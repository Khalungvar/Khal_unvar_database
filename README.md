# Khal Unvar Database

מאגר הקהילה של קהל אונגוואר: אתר שמוצג דרך GitHub Pages, והנתונים שלו יושבים בגוגל שיטס פרטי.

- **אפיון מלא:** [docs/SPEC.md](docs/SPEC.md)
- **הנתונים לא נמצאים בקוד.** רק מי שבעל המאגר שיתף איתו את הגליון יכול להתחבר ולראות אותם.

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | הדף |
| `css/style.css` | עיצוב |
| `js/config.js` | הגדרות (מזהה לוגאין, מזהה הגליון, מפתח מפות מוגבל לאתר) |
| `js/google.js` | לוגאין עם גוגל וגישה ל-Sheets API |
| `js/data.js` | קריאה וכתיבה של אנשי קשר וטלפונים לפי שמות העמודות |
| `js/places.js` | השלמת כתובות (Google Places) עם תקרה יומית |
| `js/util.js` | גימטריה, עיצוב טלפון, כללי פנייה בדואר |
| `js/app.js` | מסך אנשי הקשר |

## מה עובד כרגע (שלב 1)
התחברות, חיפוש (שם, שם חוקי, טלפון, אימייל, קוד גימטריה), כרטיס אישי, הוספה ועריכה, תגיות, השלמת תואר דו-כיוונית, השלמת כתובות, סימון לא פעיל.
