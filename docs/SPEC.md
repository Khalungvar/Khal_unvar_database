# אפיון – מערכת מסד נתונים לבית הכנסת

> מסמך עבודה. נבנה ומתעדכן שלב אחרי שלב.

## ארכיטקטורה (הוחלט)
- **התוכנה:** אתר שיושב ב-GitHub (המאגר הזה) ומוצג דרך GitHub Pages.
- **הנתונים:** גוגל שיטס. הנתונים לא נשמרים בקוד.
- **כניסה:** כל גבאי נכנס עם חשבון הגוגל שלו. ההרשאות נקבעות לפי שיתוף הגליון.

## שאלות פתוחות
1. רשימת התארים בעברית ובאנגלית, ואיך המצב המשפחתי משפיע עליהם.
2. מה המשמעות של "האם האישה בנשי".
3. רשימת המאורעות לתרומות.
4. רשימת הקשרים המשפחתיים.
5. השלמת כתובות: מתוך נתונים קיימים (חינם) או דרך גוגל.
