## שלב 3 — הסקריפטים (Apps Script), אחד אחד

הסקריפטים: **תמונות**, **עוזר AI**, **השומר (Guard) של המוסדות**, **SMS**. (המיילר של הישיבה רץ בחשבון הישיבה — רק עדכון קטן בשלב 4.)

לכל סקריפט:

1. system פותח אותו (אחרי שלב 1 הוא כבר ב־Shared Drive).
2. **אתה** מדביק את ה־Script Properties (הסודות): STRIPE\_SECRET\_KEY, TELNYX, SHARED\_SECRET, GEMINI\_API\_KEY, SOLA וכו'. אני לא רואה ולא מקליד אותם.
3. פריסה חדשה (Deploy) מ־system ← כתובת ‎/exec חדשה. system מאשר את ההרשאות.
4. **זמנים (Triggers)** — למשל שליחות SMS כל 5 דקות: יוצרים מחדש ב־system ומבטלים בישן.
5. **אני מעדכן את הכתובת** באתר (js/config.js) וב־Cloudflare Worker, ובודק.

**הסדר:** תמונות ← עוזר AI ← השומר ← SMS (אחרון — הכי רגיש, הודעות נכנסות). הפריסה הישנה נשארת פעילה עוד שבוע כגיבוי.

Telnyx ו־Stripe מצביעים ל־Worker — **לא משתנים**.
