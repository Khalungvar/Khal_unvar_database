# מפרט רשימות

Oct 21, 2026 · @יחיאל

## עיקרון

רשימה היא קבוצת **אנשים** הנקבעת לפי תנאים, וממנה יוצאים כל סוגי המשלוח דרך לשוניות. רשימה שמורה שומרת את התנאים ולא את האנשים, ולכן מתעדכנת לבד משנה לשנה.

- הגרייטע רשימות הקבועות שבקוד יורדות.
- הצ'יפים הישנים של מוסדות והסינון "יש / חסר כתובת, מייל, טלפון" יורדים מהתנאים. הלשוניות עושות את זה.

## הגדרות רשימה (⚙)

לכל רשימה כפתור ⚙ שפותח את כל ההגדרות, ואפשר לשנות אותן בכל רגע.

| נושא | החלטה |
| --- | --- |
| שם | חובה |
| הערה | לא חובה, מופיעה מתחת לשם |
| פרטי 🔒 | מופיע לכולם ברשימת הרשימות, אבל רק היוצר פותח. מנהל רואה תמיד. גבאי יכול לבקש לראות מהיוצר או ממנהל |
| ציבורי | כל הגבאים פותחים ומשתמשים |
| שינוי הגדרות | רק היוצר או מנהל |
| בקשת עריכה | גבאי מבקש מהיוצר או ממנהל. אישור לתמיד, והיוצר או מנהל יכולים להוריד אותו |
| שייכות | כלל מוסדות, או מוסד / חבורה / ארגון בשמו. קובע רק איפה הרשימה מופיעה (ובעתיד בדפי המוסדות), לא מי נכנס |
| לשונית ראשונה | איזו לשונית נפתחת ראשונה |

## מי נכנס

כל רשימה בנויה מ**בסיס אחד**, אפשר להוסיף עליו רשימות אחרות, ומצמצמים רק דרך "חוץ מ...".

1. **בסיס, בוחרים אחד:** לפי תגיות / לפי אזור / לפי משפחה / לפי תרומות. בתוך הבסיס בחירה מרובה, עם ירידה לרמות, וכל מה שנבחר מרחיב ("או").
2. **+ מרשימה אחרת:** אחת או כמה. כך מחברים בסיסים שונים. ליד כל רשימה שנוספה: ☑ "גם עליה חל החוץ מ", מסומן כברירת מחדל.
3. **⊖ חוץ מ...:** בחירה מרובה מכל הבסיסים ומרשימות אחרות. באזור: כפתור "כולם חוץ מ...".
4. **מסננים כלליים:** מצב משפחתי, כולל נפטרים / לא פעילים (ברירת מחדל לא).

**סטטוס בתגיות:** פעיל (ברירת מחדל) / יוצא / שניהם / לפי כל תגית, עם מתג ליד כל תגית שנבחרה. לא נבדק נחשב פעיל.

**משלוח לא נכנס לתנאים:** יארצייט ושמחות בעוד X ימים אינם בסיס.

## לפי תרומות ולפי משפחה

**תרומות**, כל שלב לא חובה:

- **למה:** מוסד / יערליכע קאמפיין / קאמפיין.
- **מתי (לועזי):** \[מספר\] \[חודש / שנה\] אחורה מהיום, או כל השנים, או שנה מסוימת.
- **סכום:** מינימום ו/או מקסימום, על תרומה אחת או על הסך הכל בתוך הזמן שנבחר.
- "לא נתן" = דרך חוץ מ.... תורמים שסומנו ידנית נכנסים גם כן.

**משפחה:** עד 4 מרכזים, לכל אחד צבע וסימונים משלו: הוא עצמו · בנים · חתנים · נכדים · נכדים מהבנות · נינים · אב · חותן · אחים · גיסים · מחותן קינדער · מחותן אייניקלעך. מי ששייך לשני מרכזים מקבל את שני הצבעים.

## הוספה והורדה ידנית

לא בהגדרות אלא בדף הרשימה: כפתור **+ הוספת אנשים** (אדם אחד / הדבקה / Excel) ו-✕ ליד כל שורה.

- לפני כל הוספה או הורדה: **לצמיתות** (ברירת מחדל) או **למשך \[מספר\] \[יום / חודש / שנה\]**. בהעלאה מרובה שואלים פעם אחת.
- התאמה: טלפון ← מייל ← שם + כתובת. כשיש ספק שואלים.
- מי שלא נמצא: **שורה חיצונית** רק ברשימה, עם כפתור "+ צור איש קשר".
- אין תגיות מ-Excel.

## לשוניות

👥 שמות · 📞 טלפונים · 📬 דואר · ✉ אימייל · 📊 פרטים. כל לשונית מציגה הכל, והבחירה מה לקחת נעשית ברגע השימוש.

- **איחוד (ברירת מחדל):** משלוח אחד לכתובת / מספר / מייל משותפים, על שם האב לפני הבן. מספר דירה שונה או חסר = לא מאחדים.
- **אפשרויות:** אחד על שם אחד / אחד עם כל השמות (`Mr. & Mrs. Moshe Klein / Mr. & Mrs. Yossi Klein` או `{תואר} {שם} ו{תואר} {שם}`) / לכל אחד.
- **כל רשימה זוכרת** את הבחירות האחרונות שלה.
- **שיקן** חל בלשוניות המשלוח.

## פס בעיות

בתחתית כל רשימה: 🟢 הכל תקין / 🟡 חסרים פרטים בלשונית / 🔴 X בעיות. לחיצה פותחת את הבעיות עם כפתורי תיקון.

1. אותה כתובת / טלפון / מייל בלי קשר משפחתי ← הוסף קשר / לא קרובים (רק לרשימה הזאת)
2. לא נבדק
3. אולי אותו אדם פעמיים
4. חסר שם ביידיש / אנגלית
5. חסר תואר
6. Mr. & Mrs. בלי שם אישה
7. כתובת חלקית
8. מייל שנכשל / מייל שגוי
9. נפטר ברשימה
10. נשוי ופעיל בחבורת הבחורים
11. ⏳ זמני שמסתיים השבוע
12. שורה חיצונית
13. 📭 בלי שיקן (מידע בלבד)

חסרה כתובת / טלפון / מייל מופיע בלשונית שלו, והפס צהוב.
