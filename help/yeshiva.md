# מדריך לאתר הניהול של הישיבה (ungvar.org/yeshiva)

נכנסים עם חשבון גוגל. כל אחד רואה רק את הכפתורים שיש לו הרשאה אליהם. מנהל (⚙️ צוות והרשאות) נותן הרשאות.
בראש הדף: 👤 אזור אישי, 🌓 מתג תצוגה (לפי המכשיר / כהה / בהיר), יציאה. כפתור "❓ שאל" בכל דף — העוזר הזה. העוזר יכול גם לחפש אנשים ולהציג פרטים (לפי ההרשאות של המשתמש), ולהכין הוספה של אדם חדש או עדכון טלפון — זה נשמר רק אחרי שלוחצים "✓ לאשר" בכרטיס שמופיע.

## טבלאות — מיון וסינון כמו באקסל
- לחיצה על כותרת עמודה = מיון (לחיצה נוספת = הפוך).
- ▾ ליד הכותרת = סינון: בוחרים / מורידים ✓ מערכים, חיפוש בתוך הערכים, "בחר הכל", "נקה הכל", "מיון א←ת" / "ת←א". כותרת עם ▾ אדום = יש סינון פעיל. ליד הכותרת של הדף כתוב "מוצגים X".

## הדפסות (יומן טלפונים, השתתפות, חברותות, הורים, סיכומים)
נפתח חלון הדפסה מוכן: עמוד A4 אחד, 2 טורים, משבצת בינונית, אות רגילה, שורה מרווחת לכתיבה. הבחירה היחידה: "להציג:" — כולם / רק מי שמלא בעמודה X / רק מי שריק בעמודה X. אחר כך 🖨 הדפסה.

## 🎓 תלמידי הישיבה
- חיפוש לפי שם, הורה, טלפון. "נכון לתאריך" — מי שלמד בתאריך מסוים.
- ✎ ליד "טלפון בארץ" / "טלפון בחו"ל" — עדכון הטלפון. הטלפון בחו"ל נשאר אצל הבחור גם אחרי שיצא.
- ＋ רישום תלמיד, ✎ עריכת הרישום (תאריכים, סטטוס; לסיום לימודים — "עד" תאריך / סטטוס יצא).
- 🖨 יומן טלפונים, 📒 אלפון חו"ל (נפתח באתר להדפסה), ⬇ Excel.
- ⬆ טלפונים בחו"ל מאקסל: קובץ עם עמודות שם · משפחה · טלפון. האתר מתאים לפי השם, מראה מה יישמר / מה לא נמצא / שמות כפולים — ושומר רק אחרי "💾 לשמור". מי שלא נמצא — מוסיפים ידנית ב-✎.
- אין בדף הזה שכר לימוד, תשלומים, מחיקה או חדר (זה בדפים אחרים).

## 🚪 בוגרי הישיבה — כמו התלמידים, למי שיצא. כולל הטלפון בחו"ל.

## 👔 אנשי צוות ואברכים
- פעילים / לשעבר. ✎ עריכה: תפקיד, טלפון, מייל, מ-/עד, "פעיל" (להוריד ✓ = עובר ל"לשעבר"), סוג שכר.
- מי שמסומן "יוצא" באתר הבית של הקהילה — עובר לבד ל"לשעבר".
- אברך חדש מקבל לבד את התואר "ר'" (אם אין לו תואר).
- 💰 משכורת ליד השם — רק למנהל מוסד.

## הרשאות (⚙️ צוות והרשאות — רק מנהל)
- "👑 מנהל מוסד / טכני" = משכורות, שכר לימוד, נדבות וקבלות. בלי ההרשאה הזאת אין גישה לשלושתם.
- "חובות והוצאות" — הרשאה רגילה.
- שאר ההרשאות לפי הכפתורים: תלמידים, בוגרים, הורים, צוות, השתתפות, חברותות, מלגות, ביטוח, פנימייה, מלאי המטבח, הוספה ועדכון אנשי קשר.

## ✅ השתתפות
- לשונית לכל סדר. שבוע: → שבוע קודם / שבוע הבא ← / השבוע.
- לחיצה על משבצת: ✓ נוכח → ⏰ איחור → ריק. משבצת ריקה = חסר. ✗ ישן (מלפני השינוי) — לחיצה עליו הופכת ל-✓.
- סדר עם 2 משבצות ביום (1 = תחילת הסדר, 2 = סוף): ✓ במשבצת 2 כשמשבצת 1 ריקה → משבצת 1 מסומנת ⏰ לבד.
- "✓ לכולם" ביום. 💾 שמירה (חובה לשמור!).
- 🖨 דף ריק (לסימון ביד) / 🖨 עם הסימונים / ⬇ Excel.
- יום שאף בחור לא סומן בו — הסדר "לא התקיים" ולא נחשב בכלל.
- 📊 סיכום חודשי — לפי חודש עברי. לכל סדר: נכח X / מתוך הסדרים שהתקיימו, ⏰ איחורים, אחוז. "כולל" = כל הסדרים ביחד. פחות מ-80% — באדום.
- 👤 לפי בחור — מתאריך עד תאריך, יום אחרי יום, עם אחוז כולל.
- ⏱ אברכים — כניסה ויציאה. 📝 מבחנים (אם הוגדרו).
- 🎯 בחור לסדר מסוים (למעלה בצד): לבחור שלומד רק בחלק מהסדרים — מסמנים את הסדרים שלו, והוא מופיע ביומן ובמלגות רק בהם. כל השאר — בכל הסדרים.
- 🗓 סדר עם "לוח חודשי לפי בחור" (למשל סדר בוקר): במקום היומן השבועי — בוחרים חודש עברי, מחפשים בחור (או לוחצים על שמו בטבלה), ומסמנים ✓ בלוח על הימים שסומנו בפנקס. הסכום מחושב לבד (חול / שבת לפי ההגדרות). 💾 שמירה.
- ימי עבודה של עובדים — לא כאן, אלא ב"💰 משכורות והוצאות" → 🧹 ימי עבודה (מנהל מוסד).

## 📝 מבחנים (בתוך ✅ השתתפות)
- לפי הגדרת הסדר (⚙️ הגדרות → 💰 מלגות → "חישוב"): ציון מינימלי / סכום קבוע / "✓ מולא / לא" (משבצת סימון, בלי ציון).
- "הספק יומי א'–ה'" (מסמנים בהגדרות, למשל בסדר שלישי): בדף המבחן מופיעות 5 משבצות לכל בחור — ✓ לכל יום שלמד את ההספק, "✓ לכולם" ליום. בלי מלגה.
- 📊 סיכום הספק חודשי — בוחרים חודש עברי: כמה ימים למד מתוך ימי ההספק שהתקיימו, ואחוז. 🖨 / ⬇ Excel.

## 🎖 מלגות (דף נפרד)
- לשונית לכל סוג מלגה. בוחרים חודש עברי. "גם מי שלא מגיע לו" — להציג את כולם.
- ✉ פתקי מלגה (A4 למעטפה עם חלון), 💵 הכנת מזומן (כמה שטרות ומטבעות), 🖨 סיכום, ⬇ Excel.
- ⚙️ סוגי מלגות ונוסח הפתקים: לכל סוג — שם, אילו סדרים (2 סדרים ומעלה = מלגה אחת מאוחדת: שורה לכל סדר באותו פתק וסכום אחד), ונוסח: פנייה, ברכה, פתיחה, שורת סכום, מאמרים. בנוסח אפשר לכתוב {שם} {חודש} {סכום}.
- הסכום לכל השתתפות / מבחן — ב⚙️ הגדרות הסדרים. "₪ בשבת" — סכום אחר לשבת (למשל 25 בחול, 50 בשבת).
- ✓ שולם: בטבלה, עמודת "שולם" — מסמנים מי קיבל את המלגה (נשמר לכל סוג ולכל חודש). "✓ סמן הכל כשולם". למעלה: שולם / נשאר לשלם.
- 🖼 בלאנק לפתק: ב⚙️ סוגי מלגות, לכל סוג — "⬆ העלאת בלאנק" (תמונה של דף A4). בלי בלאנק משלו — הבלאנק הכללי.

## 🤝 חברותות
- בוחרים זמן וסדר (הסדר הפעיל מודגש בכחול, ושמו ליד הכותרת). כותבים / בוחרים חברותא — אצל הבחור השני נרשם לבד אם ריק. 💾 שמירה. 🖨 הדפסה, 🖨 דף אברכים.

## 📄 דפים קבועים (הרשאה: "דפים קבועים")
- 🕯 זמני השבת, 📜 שיעור ליל שישי, ותבניות נוספות.
- 📜 שיעור ליל שישי: הפרשה, השנה והתאריך מתמלאים לבד לפי יום ההפקה; ממלאים שם המעביר, התואר והשעה → ⬇ Word מוכן. הערכים האחרונים נשמרים.
- ➕ תבנית חדשה: מכינים דף ב-Word, ובמקום מה שמשתנה כותבים {{שם השדה}}. שדות אוטומטיים: {{פרשה}} {{שנה}} {{תאריך}} {{תאריך לועזי}} {{יום}}. מעלים את הקובץ — המערכת מזהה את השדות.

### 🕯 זמני השבת
- בוחרים ערב שבת (או שבוע קודם / הבא). הזמנים מחושבים לפי ירושלים מהלוח של הקהילה: הדלקה 40 דק' לפני השקיעה, שקיעה, מנחה, סדר לימוד (שעה לפני שחרית), שחרית, סוף זמן קריאת שמע, מנחה ושל"ס, מוצאי שבת ר"ת.
- כל זמן אפשר לשנות. כותבים את האורח בסעודת ליל שב"ק (ריק = בלי). ⬇ Word לפי התבנית — מקבלים קובץ וורד בתבנית של הישיבה עם הרקע. "⟳ לחשב מחדש מהלוח" מחזיר את הזמנים המקוריים.

## 🍳 מלאי המטבח
- למעלה: סה"כ פריטים, לחידוש, עומדים לפוג / פגו, שווי מלאי (לחיצה = סינון).
- 📦 מלאי: חיפוש, קטגוריה, ספק, מיון (א-ב / תוקף / כמות), − / + לכמות, ✎ עריכה, ＋ פריט חדש, ⬆ ייבוא מאקסל, ⬇ Excel.
- 🧊 הקפאה: כפתור 🧊 ליד מוצר — לא בשימוש כרגע: בלי התראות ובלי הזמנות. "🧊 מוקפאים" מציג אותם, ♨ מחזיר לשימוש.
- "שימוש בשבוע" — כמה משתמשים בשבוע (בערך).
- קרטונים: "יחידות בקרטון" במוצר — המלאי, המינימום והשימוש ביחידות; ברשימת הקניות מזמינים בקרטונים, ו"✓ הגיע" מוסיף קרטונים × יחידות.
- 🚚 ספקים: שם, טלפון (וואטסאפ ישיר לספק מרשימת הקניות), איש קשר, מייל, ימי הזמנה. "⬆ ייבוא ספקים מאקסל".
- התראה מוקדמת: כשהמלאי ≤ מינימום + (שימוש ליום × ימי אספקה) — "להזמין עכשיו". תוקף — 5 ימים לפני.
- 🛒 רשימת קניות: לפי ספק, כמות להזמנה (אפשר לשנות), 💬 וואטסאפ, 📋 העתקה, 📝 נרשם כהוזמן, ✓ הגיע — להוסיף למלאי, 🖨 PDF, ⬇ Excel.
- הזמנה קבועה: בפריט — "יום הזמנה קבוע" ו"כמות תקן". ביום הזה מופיעה תזכורת; כמות להזמנה = תקן − מה שנשאר.
- 📜 היסטוריית הזמנות, "✓ הגיע" להזמנה שהגיעה.
- 🔑 אנשי המטבח וסיסמאות (למנהל): לכל עובד שם + סיסמה; "רואה מחירים" — רק אם מסמנים. העובדים נכנסים בלי גוגל בדף ungvar.org/yeshiva/kitchen/. הם מעדכנים כמויות, רשימת קניות, "הגיע". פריט חדש או מחיקה שלהם — מגיעים לאישור: "📨 בקשות מאנשי המטבח" → ✓ לאשר / ✗ לדחות. 5 סיסמאות שגויות = נעילה ל-10 דקות. סיסמה חדשה מוציאה את מי שנכנס עם הישנה.

### 🎉 הזמנות מיוחדות (בתוך מלאי המטבח)
- "＋ הזמנה מיוחדת חדשה": שם (פורים, שבועות, שבת שהרבי נמצא…), תאריך, ורשימת מוצרים — מהמלאי או מוצר חדש, כמות, יחידה, ספק.
- נשמר כתבנית: בפעם הבאה ✎ לעדכן תאריך, או 📋 לשכפל.
- "🛒 הכן הזמנה": רשימה לפי ספק, אפשר "לקזז מה שיש כבר במלאי", לשנות כמויות, 💬 וואטסאפ, 📋 העתקה, 📝 נרשם כהוזמן, ✓ הגיע — להוסיף למלאי.
- גם אנשי המטבח (בדף שלהם) יכולים ליצור ולהכין הזמנות מיוחדות.

## 🎉 עדכון שמחות (הרשאה: "עדכון שמחות")
- בוחרים סוג שמחה ובעל השמחה (בחור / איש צוות / אברך), שם הילד והצד השני אם צריך, והשבת. "🎉 עדכון באונגוואר + דף מזל טוב" — השמחה נכנסת לרשימת השמחות של אונגוואר, ונפתח דף מזל טוב מעוצב על הבלאנק (🖨 הדפסה / שמירה כ-PDF). הנוסח ניתן לשינוי לפני כן. "🖨 רק דף מזל טוב" — בלי לעדכן באונגוואר.
